# Modular Hub 文档导航

这里归档本会话两轮架构讨论，供逐步阅读；不是已经实现的功能说明。

**当前只需要记住：先把现有后台与 Vben 的基础闭环做好，再接入独立业务应用。**

## 建议阅读顺序

1. 先读 [项目决策与版本范围](00-overview.md)：理解现在做什么、不做什么。
2. 准备开发时读 [V0.1 设计索引](03-v0.1/README.md)，只展开当下相关的专题。
3. 真正开始编码前读 [任务清单](03-v0.1/tasks.md)，从 T01 开始，不一次实施全部任务。

其他内容按需查阅，不必从头读完。

2026-11-13 起，前后端、本文档目录和设计原型统一由根目录 Git 仓库管理。迁移方式、历史查询和提交约定见 [统一仓库管理](git-management.md)。下列架构文章保留此前讨论背景，功能状态以当前工程实现为准。

## 文档状态与使用规则

- 来源：2026-11-08 会话中的第一轮架构审查和第二轮 V0.1 详细设计。
- 本次是按主题整理归档，不是逐字聊天备份；重复内容已合并，第二轮对 V0.1 的收敛决策优先。
- “现状”来自此前静态审查；本次归档没有重新运行系统或全面复核代码。
- “建议”“拟新增”“任务”都不是已完成项。测试、构建、迁移和部署尚未由本会话执行。
- 本目录只说明 Modular Hub 跨工程规划；[后端原有文档](../backend/docs/README.md)继续保留，不迁移、不覆盖。
- 不在文档中保存凭据、真实连接串或个人数据。代码链接使用仓库相对路径，便于移动项目。
- 后续实现改变契约时，应更新对应专题和任务状态，避免同时维护多份互相矛盾的设计。
